# My First Linux Terminal & CTF Challenge Write-up

مرحباً بك في مستودع توثيق رحلتي في تعلم نظام لينكس والتحديات الأمنية (CTFs). هذا أول لاب عملي قمت بحله وتطبيق الأوامر الأساسية عليه بنفسي!

---

## الأوامر التي أتقنتها واستخدمتها:
- "pwd": لمعرفة المسار الحالي للملفات.
- "cd" & "cd ..": للتنقل السريع بين المجلدات بعمق.
- "ls": لعرض محتويات المجلدات.
- "ls -a": لإظهار الملفات والمجلدات المخفية (التي تبدأ بنقطة مثل .hidden).
- "ls -lh": لعرض تفاصيل الملفات مع حجمها بصيغة سهلة القراءة (مثل MB).

---

## تفاصيل الحل (Challenge Write-up):
تمكنت بفضل الله من حل "التحدي الشامل للمستوى الأول" واستخراج جميع الأدلة المخفية كالتالي:

1. **الدليل الأول (الملف المخفي الرئيسي):**
   - **الأمر المستخدم:** `ls -la` في المجلد الرئيسي.
   - **النتيجة:** `.evidence_1.txt`

2. **الدليل الثاني (تحليل حجم الملفات الثقيلة):**
   - **الأمر المستخدم:** `ls -lh` داخل مجلد sector_A.
   - **النتيجة:** حجم ملف payload.bin كان `12M`.

3. **الدليل الثالث (الغرفة المظلمة المخفية):**
   - **الأمر المستخدم:** الدخول لمجلد `ghost_dir` واستخدام `ls -a`.
   - **النتيجة:** `.evidence_2.txt`

4. **الدليل الرابع (المسار الكامل للهدف الأخير):**
   - **الأمر المستخدم:** تتبع المجلدات بـ `cd` واستخدام `pwd` في النهاية.
   - **النتيجة:** `/home/kali/ultra_challenge/sector_A/sector_B/vault`
